# 🛒 Blinkit Grocery Data Analysis (Exploratory Data Analysis)

## 📌 Project Overview
This project carries out an **Exploratory Data Analysis (EDA)** on Blinkit grocery sales data using **Python** in a Jupyter Notebook environment. The goal is to analyze product performance, sales distribution, outlet efficiency, and customer purchasing trends to derive actionable insights for business optimization.

---

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `seaborn`, `matplotlib`

---

## 🔍 Key Data Preprocessing & Cleaning
* **Data Cleaning:** Identified and handled missing/null values across key fields.
* **Data Formatting:** Standardized column names and item categories for clean aggregation.
* **Feature Engineering:** Calculated overall sales metrics, ratings, and outlet-wise revenue performance.

---

## 📈 Key Insights & Analysis
1. **Sales & Item Performance:** Identified top-selling item categories and high-revenue grocery products.
2. **Outlet Type Efficiency:** Analyzed sales distribution across different outlet types (e.g., Supermarkets vs. Grocery Stores) and location tiers.
3. **Rating & Visibility Impact:** Explored the correlation between product visibility, ratings, and total revenue.
